# 教学资料检索·样例（输入 → 输出）

> 演示标准输出行为：含「无冲突备课」与「冲突按四步法」两类；付费 / 学术资源按"仅定位、不取全文"处理（见 SKILL.md 使用前提与硬性规则）。

## 样例一：备课场景（网络检索，无冲突）
**输入**：帮我找一份人教版高一物理"牛顿第二定律"的教案，要能直接上课用。

**输出（节选）**
```
【检索摘要】学科=物理，学段=高一，版本=人教版，主题=牛顿第二定律，类型=教案，场景=备课，模式=网络。信源：一级 + 二级定位。
【推荐资料列表】（按综合分降序）
1. 《牛顿第二定律》教学设计（人教版必修一）— 国家中小学智慧教育平台（免费）— 高一/人教版 — 综合分 4.30 / ★优
   核心：实验引入→F=ma 推导→三性→例题。可复用：含完整课堂活动与板书。参考文献条：人民教育出版社. 必修第一册教师教学用书. 人教社, 2023.
2. 牛顿第二定律教案（分层练习）— 正规门户（免费）— 高一/人教版 — 综合分 3.55 / ★优
【矛盾点提示】无。
【补充说明】知识点已对照 2022 版课标核验，无"待核实"项。
```

## 样例二：冲突场景（须按四步法）
**输入**：查一下"勾股定理"的引入方式，网上说法不一，帮我定一个。

**输出（节选）**
```
【检索摘要】主题=勾股定理引入，类型=教学设计，场景=备课，模式=网络。来源间存在冲突。
【推荐资料列表】（按综合分降序）
1. 面积法引入（赵爽弦图）— 人教版教材配套教师用书（一级）— 综合分 4.45 / ★优 — ★★★★★
2. 测量归纳法引入 — 某教师博客（三级）— 综合分 2.95 / < 3.0 降级 — ★★★☆☆
【矛盾点提示】
- 冲突点：引入路径有"面积法(赵爽弦图)"与"测量归纳法"两种。
- 观点A（面积法）：来源=教材配套教师用书，严谨、与教材一致。
- 观点B（测量归纳法）：来源=教师博客，直观但需补严格证明。
- 提示：采信教材配套方案（A）为课堂主推；追求探究感可用 B 作铺垫。
【补充说明】可信度层级可区分，已择优采信并标注分歧，不强行掩盖。
```

## 样例三：本地 / 知识库检索
**输入**：在我本地 `D:/备课资料/物理/` 文件夹里找牛顿第二定律的学案。

**输出（节选）**
```
【检索摘要】主题=牛顿第二定律，类型=学案，场景=备课，模式=本地（D:/备课资料/物理/）。仅在该目录内检索，未检索目录外。
【推荐资料列表】
1. 牛顿第二定律学案.docx — 本地文件（免费）— 高一/人教版 — 综合分 3.85 / ★优 — ★★★★☆
   核心：目标/预习/探究/练习。可复用：可直接印发。
【补充说明】未检索目录外其他内容；如需全网补充资料可切换网络模式。
```

## 样例四：异常处理话术（空结果 / 付费墙 / 超边界）
> 演示三类异常的标准诚实回应，核心原则：**不虚构、不假装、不强行执行**。

**输入 A（空结果）**：帮我找一份"量子纠缠"的小学二年级教案。

**输出 A（节选）**
```
【检索摘要】主题=量子纠缠，学段=小学二年级，类型=教案，模式=网络。
【推荐资料列表】（空）
【补充说明】小学二年级课标无"量子纠缠"相关内容，全网权威/正规信源均未命中适龄资料。
建议：① 放宽学段至高中物理选修；② 改主题为"趣味科学小实验"类科普素材；③ 若仅作兴趣拓展，可检索科普微课（三级补充，须教师把关）。不返回虚构内容。
```

**输入 B（付费墙）**：找一篇关于"大单元教学"的期刊论文全文。

**输出 B（节选）**
```
【检索摘要】主题=大单元教学，类型=论文，模式=网络（学术）。
【推荐资料列表】
1. 《核心素养下的大单元教学设计》— 王某某 — 某教育期刊, 2023 — 题录+摘要（需登录获取全文）
   摘要：…（一句话概括）。全文入口：知网/万方，标"需登录获取"。
【补充说明】学术资源仅出题录+摘要，不复制全文；全文请由您的账号在对应平台获取。免费替代：国家中小学智慧教育平台"大单元教学"课例（一级，免费）。
```

**输入 C（超边界）**：帮我把整本高一物理教材写出来。

**输出 C（节选）**
```
【检索摘要】请求=生成整本高一物理教材。
【适用边界提示】本技能仅做"检索+整理+校验+输出"，不生成整本教材、不做学情分析/阅卷批改、不替代教研审核。
【可替代做法】① 检索现成教材配套教案/课件（请输入具体课题）；② 逐章节检索备课资料包；③ 教材原文请使用正版出版物。
```
