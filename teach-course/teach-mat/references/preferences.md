# 教学资料检索·固定偏好细则

> `SKILL.md` 的详细参考。核心固定逻辑以本文件为准；个性化选项可按需开关。
> 原草稿中"彻底解决随机性""杜绝知识性错误""永远给唯一答案"等绝对化表述，已修正为可执行、可核验的措辞。

## 一、信源分层（检索优先级）
- **一级·权威**：教育部官方平台、国家中小学智慧教育平台、人教社 / 各版本教材出版社官方资源、省市级官方教研院发布资源。
- **二级·正规门户（仅检索定位）**：学科网、教习网、21 世纪教育网等——付费 / 需登录内容须标注并征得同意。
- **三级·谨慎参考**：普通教师博客、学校自建资源、论坛分享——仅补充，须交叉验证。
- **学术资源**：中国知网 CNKI（含海外版 `tr.oversea.cnki.net`）、万方、维普——仅出**题录 + 摘要**（标题 / 作者 / 来源 / 年 / 摘要），不复制全文，全文入口标"需登录获取"。
- **永久屏蔽**：来源不明、无原创认证、含明显错误或营销导向的文档分享站（百度文库、道客巴巴等）；抖音、快手等流量导向自媒体；任何含明显知识错误、软文、版权存疑内容。

## 二、各信源固定检索入口写法（减少试错、提升命中）
> 不同信源有各自最有效的检索句式，按源套用可显著降低空结果率。

| 信源 | 推荐检索入口写法 | 备注 |
|------|----------------|------|
| 国家中小学智慧教育平台 | `国家中小学智慧教育平台 + 学科 + 学段 + 课题名` | 官方课例 / 课件首选 |
| 人教社 / 出版社官网 | `人教版 + 年级 + 课题 + 教案/课件/site:pep.com.cn` | 替换对应出版社域名 |
| 省市级教研院 | `XX省/市 教研院 + 学科 + 课题 + 教学设计` | 区域官方资源 |
| 学科网 / 教习网 / 21 世纪 | `课题名 + 教案/试卷 + 学段 + 版本`（仅定位题录） | 付费须标"需登录获取" |
| 中国知网 CNKI | `题名=课题 AND 关键词=学科` 或站点高级检索 | 仅题录+摘要；海外用 `tr.oversea.cnki.net` |
| 万方 / 维普 | `课题 + 学科 + 期刊/学位` | 仅题录+摘要 |
| 北师大出版社 | `北师大版 + 年级 + 课题 + 课件/site:bnup.com.cn` | 北师大版专属 |
| 外研社 | `外研版 + 年级 + 模块 + 教案/site:fltrp.com` | 英语外研版专属 |
| 教习网 | `课题 + 学段 + 教案/学案`（定位） | 与学科网互补 |
| 央视 / 官方媒体号 | `CCTV + 课题 + 纪录片/公开课` | 视频 / 科普素材 |
| B站 官方号 | `官号名 + 课题 + 微课`（如"国家中小学智慧教育平台"账号） | 微课 / 动画素材 |
| 维普资讯 | `课题 + 学科 + 文献` | 学术论文题录 |

> 检索入口写法随信源界面调整而更新；新增官方 / 权威信源时按上表格式补入即可。

## 三、分级并行与降级细则
- **并行派发**：一级 / 二级 / 三级各开一路，同一回复内发起、分别回传，主流程不串行等待；单路超时即降级，不阻塞他路（详见 SKILL.md「并行采集与防卡顿降级」）。
- **降级顺序**：换词 → 换检索入口写法 → 换同级信源 → 跨级降级（一级→二级→三级）→ 记缺失跳过（标注"该信源本次未取得"后继续）。
- **铁律**：拒绝堵塞——任何一路失败都不得拖垮整次检索或倒逼虚构内容。

## 四、内容筛选规则
- **版本 / 学段 / 知识点匹配**：严格匹配用户指定版本与学段；未指定版本按最主流通用版本，强依赖版本时先确认。
- **免费 / 开放优先**：优先免费开放资料；优质付费资源标"付费 / 需登录"并征得同意，不默认提供全文。
- **时效性**：默认优先近 3 年（经典 / 纲领性内容除外）；陈旧资料须标注年份。

## 五、冲突处理四步法
1. 梳理冲突点，逐条列出。
2. 按可信度排序：官方教材及配套教师用书 > 省 / 市官方教研院 > 知名权威教育平台 > 普通教师博客。
3. 可信度层级可区分 → 采信高层级来源，标注分歧及来源。
4. 可信度同级、无法判定 → **完整呈现各方观点与来源，提示用户自行甄别、按需选用，不强行统一**。

## 六、全教学场景适配
- **备课**：教案、教学设计、课件、学案——强调可操作性与目标对齐。
- **授课**：课件、微课、课堂活动——强调重点突出、互动可落地。
- **出题**：习题、试卷、考点精炼——强调难度分层、答案与解析完整。
- **复习**：知识梳理、错题归因、专题训练——强调体系化与易错提示。
- **教研**：课标解读、课例、论文——强调前沿性与可借鉴性。

> 各场景的填空式模板、触发词与标配清单见 `references/scene-templates.md`，本处仅作要点速览，避免两处内容漂移。

## 七、硬性执行规则
- 输出结构化成品（摘要 + 列表 + 要点），不堆砌链接。
- 每条资料附：标题、来源（免费 / 付费）、适用学段版本、**综合分（≥3.5 标 ★优）**、核心内容、可复用要点。
- 评估委员会四维加权评分（5 分制）：**可信度 × 0.35 + 相关性 × 0.30 + 时效性 × 0.20 + 完整性 × 0.15**，权重与门槛须严格遵守（详见 SKILL.md 阶段四）。
- 知识点 / 版本 / 学段必校验；无法核实的内容显式标"待核实"。
- 合并重复同源资料；多来源一致做整合，分歧按「五·冲突处理四步法」处理。

## 八、可配置项（按需开关，不改动核心逻辑）
- 偏好信源清单（在白名单内增删）。
- 输出篇幅（简版 / 详版）。
- 语言风格（口语化 / 学术化）。
- 是否附带"相似资料"推荐。
