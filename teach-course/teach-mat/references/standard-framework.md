# 标准版溯源（Standard Framework · Traceability）

> 本文件用于追溯本技能的设计来源与本版相对原版的变化点，确保每次重构都有"可对照的原稿"，避免无锚点修改造成回归。

## 一、原稿来源
- **来源一**：Walker《AI 教学资料搜索 Skill 专属偏好框架（草稿）》——本技能 v1.0.0 的直接骨架来源，含 8 节偏好规则、五场景适配思路、冲突处理四步法雏形。
- **来源二**：SkillHub 社区 `teach-mat`（user_ff429dcb）—— TRACE 质量框架（T 可信任 / R 可靠 / A 适用 / C 规范 / E 有效），被本技能用于章节可信度标注与诚实性约束。
- **来源三**：SkillHub 社区 `sunny-cx-jiaoxue`（teaching-material-search）——「并行检索 + 降级链 + 压缩回传」工程模式；本技能**仅取其原则**（不搬脚本，避免与运行环境记忆系统重复及硬编码 Windows 路径的兼容风险）。

## 二、本版（V1.0.1）相对原版的变化点
- **5 阶段对齐**：原 9 步 SOP 重排为 5 阶段（意图识别 → 多源并行 → 提取去重 → 评估委员会 → 结构化输出）。
- **评估委员会四维加权评分**：从原"五维 1–5 星"改为"四维加权 × 5 分"，权重 = 可信度 0.35 + 相关性 0.30 + 时效性 0.20 + 完整性 0.15；综合分 ≥ 3.5 优先。
- **综合分列**：输出「推荐资料列表」每条加 综合分，≥3.5 标 ★优。
- **中英双语 frontmatter**：补 `name_en` / `description_en` / 英文 triggers，覆盖英文教学场景。
- **并行采集硬性上限**：并行路数从「无限」收紧为 **最多 3 路**（一级 / 二级 / 三级各一路），新增"不得超 3 路"铁律。
- **删除记忆/自学习**：原"记忆与自优化"节删除，避免与运行环境记忆系统重复；Token 节省里的"先库后网"改为仅依赖"用户指定本地/知识库 或 同一次会话已检索过"。
- **file生成触发节点**：阶段五新增「文件生成触发」节点——以纯 markdown 形式指下游文件生成技能，**不内置生成脚本**，保持"纯规范、无脚本"定位。
- **场景适配去重**：`preferences.md` 的「六、全教学场景适配」精简为要点速览，详情统一指向 `references/scene-templates.md`，避免两处内容漂移。
- **章节编号清理**：`preferences.md` 原"一·之二 / 一·之三" hack 改为规范的一~八 顶层编号。
- **异常话术样例**：`examples.md` 增补样例四，覆盖"空结果 / 付费墙 / 超边界"三类标准诚实回应。

## 三、回归风险清单（下次修改须逐条核对）
- 信源分层、白/黑名单、付费资源规范：未动；若改动须保持「仅定位不取全文」。
- 冲突处理四步法：未动；若改动须保持「同级不强行统一」。
- 纯规范、无脚本定位：必须保持。任何将本技能脚本化的尝试须先评估运行环境兼容性。
- 评估委员会权重：≥3.5 优先、< 3.0 降级——若调整权重，须重跑"标准版溯源"本节。
- 并行上限 3 路：硬性。若要放开，须同步给出 Agent 串行调度的对应约束说明。
