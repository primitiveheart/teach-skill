# 教学资料检索·五场景填空式模板库

> 覆盖备课 / 授课 / 出题 / 复习 / 教研五类场景。收到对应触发词即用对应模板，填空产出，确保每个场景的「标配清单」不遗漏。优先级：**本次会话明示 > 本文件默认**。

## 一、备课场景
- **触发词**：备课、写教案、找课件、教学设计、学案、备课资料包。
- **标配清单**：教案 / 教学设计 + 课件 + 学案（三选其主，可全要）+ 目标对齐说明。
- **填空模板**：
  ```
  【场景】备课
  【学科/学段/版本】____ / ____ / ____
  【课题/知识点】____
  【需要资料】教案( ) 课件( ) 学案( ) 其他( )
  【输出要求】强调可操作性与目标对齐；附课堂活动与板书建议
  ```

## 二、授课场景
- **触发词**：上课用、课件、微课、课堂活动、公开课、讲授。
- **标配清单**：课件 + 微课（可选）+ 课堂活动设计。
- **填空模板**：
  ```
  【场景】授课
  【学科/学段/版本】____ / ____ / ____
  【课题/知识点】____
  【需要资料】课件( ) 微课( ) 课堂活动( )
  【输出要求】重点突出、互动可落地；标注各环节时长建议
  ```

## 三、出题场景
- **触发词**：出题、习题、试卷、考点精炼、练习、刷题。
- **标配清单**：习题 / 试卷 + 答案 + 解析（答案与解析完整为硬要求）+ 难度分层。
- **填空模板**：
  ```
  【场景】出题
  【学科/学段/版本】____ / ____ / ____
  【考点/知识点】____
  【题型/数量】____（如：选择5+填空3+解答2）
  【难度分层】基础( ) 中等( ) 拓展( )
  【输出要求】答案与解析完整；标注难易与对应知识点
  ```

## 四、复习场景
- **触发词**：复习、知识梳理、错题、专题训练、备考。
- **标配清单**：知识梳理 + 易错提示 + 专题训练（可选）。
- **填空模板**：
  ```
  【场景】复习
  【学科/学段/版本】____ / ____ / ____
  【复习范围】____（单元/专题/整册）
  【需要资料】知识梳理( ) 错题归因( ) 专题训练( )
  【输出要求】体系化呈现；突出易错点与归因
  ```

## 五、教研场景
- **触发词**：教研、课标解读、课例、论文、评比、课题。
- **标配清单**：课标解读 + 课例 + 论文 / 文献题录（仅定位）。
- **填空模板**：
  ```
  【场景】教研
  【学科/学段】____ / ____
  【研讨主题】____
  【需要资料】课标解读( ) 课例( ) 论文题录( )
  【输出要求】强调前沿性与可借鉴性；论文仅出题录+摘要，不复制全文
  ```

## 使用说明
- 模板仅作「结构引导」，最终仍套用 SKILL.md「标准输出格式」四模块产出。
- 同一请求跨场景时，以用户主目标场景为准，次要场景资料作「相似资料」附带。
- 出题场景习题优先、教研场景文献优先，资源类型主次随场景动态定，不套全局硬顺序。
