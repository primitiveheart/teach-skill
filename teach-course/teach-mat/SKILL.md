# 教学资料检索

> 设计参照通用技能质量框架 TRACE（T 可信任 / R 可靠 / A 适用 / C 规范 / E 有效），确保技能可被各类通用 Agent 稳定加载与使用，不依赖特定平台。

## 目的
为教师提供**可直接落地**的教学资料：通过网络搜索（及可选的本地文件夹 / 知识库检索），按固定搜索偏好产出结构化成品，缓解通用 AI 搜索常见的随机性强、堆链接、内容不准、信息冲突、不贴合教学场景等问题。

## 使用前提（Trust 可信任）
- **国内网络可跑通、完整中文交互**：默认依赖运行环境的网络搜索工具（`web_search` / `WebFetch`）检索国内可访问的中文教育信源；不依赖任何海外 API。
- **纯规范、无脚本**：本技能仅是一套检索偏好与输出规范，不含可执行代码、不请求无关权限、不读取范围外文件，通过安全审查。
- **本地 / 知识库可选**：用户指定本地文件夹时，用本地文件检索工具**仅在该目录内**搜索；指定知识库时用知识库检索能力**仅在该库内**查询，均不外溢。
- **学术 / 付费资源仅限定位**：知网（国内主站 `cnki.net` 优先；海外版 `tr.oversea.cnki.net` 适用于跨境 / 海外网络环境）、万方、维普及学科网等付费 / 版权资源只做"发现 + 题录摘要 + 来源标注"，不复制全文，全文由用户账号获取。
- **关键内容需教师把关**：技能"最大限度避免"知识性错误并标注存疑，但 LLM 有幻觉风险，正式用课前请教师最终核验。
- **信源时效需人工维护**：课标 / 版本（现行以 2022 版为准）、"近3年"等时效表述需随官方更新手动同步。

## 触发条件（Adaptability 适用）
当用户提出以下任一类请求时启用：
- 检索 / 准备具体教学资料：教案、课件、习题、教学设计、微课、学案、试卷、备课资料包。
- 指定学科 / 学段 / 版本 / 知识点后要求"找 / 搜 / 给 / 对比 / 核实"相关材料。
- 校验某份资料准确性，或对比多来源差异。
- 指定本地文件夹 / 知识库，要求"在里面找 / 搜 XX 教学资料"。

> 顶部 `triggers` 字段已给出显式触发词清单，Agent 可在不依赖 description 语义猜测的情况下直接命中启用；若用户未显式命中但有上列意图，仍按 description 自然启用。

### 适用边界（明确不做什么，避免误调用）
- 仅做"检索 + 整理 + 校验 + 输出"，**不**生成整本教材、**不**做学情分析 / 阅卷批改、**不**替代学校教研审核、**不**编写需版权授权的整套 commercial 教辅。
- 网络不可用且无本地 / 知识库指定时，仅能做离线格式建议，会明确告知而非假装检索成功。

## 输入参数（Convention 规范）
| 参数 | 说明 | 缺省处理 |
|------|------|----------|
| 学科 / 学段 | 如 物理 / 高一 | 必填，缺失则澄清 |
| 教材版本 | 人教版 / 北师大版等 | 未指定按最主流通用版本；结果强依赖版本时先确认一次 |
| 知识点 / 主题 | 如 牛顿第二定律 | 必填，缺失则澄清 |
| 资料类型 | 教案 / 课件 / 习题… | 缺失则按场景默认 |
| 场景 | 备课 / 授课 / 出题 / 复习 / 教研 | 缺失则按类型推断 |
| 检索范围 | 网络（默认）/ 本地文件夹路径 / 知识库名 | 默认网络 |

## 搜索偏好（检索什么源、不搜什么）
### 信源分层（优先级从高到低）
1. **一级·权威**：教育部官方平台、国家中小学智慧教育平台、教材出版社官方资源、省市级官方教研院。
2. **二级·正规门户（仅检索定位）**：学科网、教习网、21 世纪教育网等——付费 / 需登录内容须标注并征得同意。
3. **三级·谨慎参考**：普通教师博客、学校自建资源、论坛分享、官方媒体教学号（央视 / B站官方号微课）——仅补充，须交叉验证。
4. **学术资源**：中国知网（主站优先，海外版 `tr.oversea.cnki.net` 作跨境补充）、万方、维普——仅出**题录 + 摘要**，不复制全文。
5. **永久屏蔽（不搜）**：来源不明 / 无原创认证 / 明显错误或营销导向的文档分享站（百度文库、道客巴巴等）；抖音、快手等流量导向自媒体；任何含明显知识错误、软文、版权存疑内容。

> 各信源固定检索入口写法、北师大社 / 外研社等版本专属官网、央视 / B站官方号的具体检索句式，见 `references/preferences.md`「各信源固定检索入口写法」。

### 只搜相关资料（不发散）
- 严格围绕用户给定的学科 / 学段 / 版本 / 知识点 / 资料类型检索，不扩展到无关学科、无关主题或泛娱乐内容。
- 匹配版本 / 学段 / 主题后才纳入；未指定版本按主流默认，强依赖版本时先确认。

## 执行流程（5 阶段对齐，每次按序执行）

### 阶段一 意图识别与查询扩展
- 读取输入参数表，判断检索模式（网络 / 本地 / 知识库）。
- 必填项（学科 / 学段 / 知识点）缺失 → 提 1 个简洁澄清问题。
- 资料类型 + 场景 → 套用对应 `references/scene-templates.md` 模板，产出填充后的「查询意图卡」（含核心词 + 同义词 + 上位词）。
- 退出阶段：已具备「检索模式 + 关键词集合 + 场景模板」三要素后方可进入阶段二。

### 阶段二 多源并行搜索（最多 3 路，严格 ≤3）
- **一路·一级权威**：教育部 / 国家平台 / 出版社 / 省市级教研院。
- **二路·二级正规门户（仅定位）**：学科网 / 教习网 / 21 世纪教育网等仅做发现与题录。
- **三路·三级谨慎参考**：教师博客 / 论坛 / 学校自建资源 / 官方媒体教学号做补充。
- 三路**同一条回复内发起、分别回传**，主流程不串行等待；任一路超时即走降级，不阻塞其他路。
- **五步降级链（拒绝堵塞铁律）**：
  1. **换词**：同义 / 上位 / 教材章节名重试。
  2. **换方法**：换检索入口写法（详见 `references/preferences.md`「二、各信源固定检索入口写法」）。
  3. **换同级信源**：一级内换另一官方站；二级内换另一门户。
  4. **跨级降级**：一级 → 二级定位 → 三级补充。
  5. **记缺失跳过**：在【补充说明】标注「该信源本次未取得」，继续其余已得结果，绝不凑齐拖延或虚构。
- **异常话术**：
  - 空结果 → 如实告知，建议换词 / 放宽学段 / 改本地或知识库，不返回虚构内容。
  - 仅命中付费墙 → 显式「需登录获取」+ 免费替代建议，不假装获取全文。
  - 超边界（如生成整本教材）→ 说明本技能不做该项 + 给出可替代做法。
- 退出阶段：每路回传「标题 + 来源 + 适用性 + 一句话摘要」的紧凑条目。

### 阶段三 结构化提取与去重
- 提字段：标题 / 来源（免费·付费·本地·知识库）/ 适用学段版本 / 类型 / 核心内容摘要 / 可复用要点 / 参考文献条。
- 合并重复同源；按 2022 版课标核对关键知识点，无法核实显式标「待核实」。
- 删除错配、过期（约超 3 年且非经典）、低可信项。

### 阶段四 智能筛选与评估（评估委员会）
- **四维加权评分（5 分制）**：
  - 可信度 × **0.35**（权重最高）
  - 相关性 × **0.30**
  - 时效性 × **0.20**
  - 完整性 × **0.15**
- **综合分 ≥ 3.5 优先采纳**；< 3.0 降级或剔除。
- 冲突处理：可信度层级可区分 → 采信高层级，标注分歧；同级无法判定 → 走「冲突处理四步法」完整呈现各方观点与来源，不强行统一。

### 阶段五 结构化输出 + 自检 + 文件生成触发
- **输出**：严格套用「标准输出格式」四模块——
  1. **检索摘要**：检索了什么（学科 / 学段 / 版本 / 主题 / 类型 / 场景 / 检索模式）+ 所用信源层级。
  2. **推荐资料列表**：按综合分降序，每条含 标题 / 来源（免费·付费·本地·知识库）/ 适用学段版本 / **综合分（≥3.5 标 ★优）** / 核心内容摘要 / 可复用要点 / 参考文献条（作者. 标题. 来源, 年份）。
  3. **矛盾点提示**（存在冲突时）：分点列各方观点 + 来源 + 建议或「请按需选用」提示。
  4. **补充说明**：版本 / 学段注意 / 「待核实」项 / 可替代检索建议。
- **自检**：版本·学段·知识点已校验 / 无未标注不确定项 / 未检索无关数据 / 未超边界。
- **文件生成触发（可选）**：用户要求产出 docx / pptx / xlsx 时，调用相应下游文件生成技能；本技能**仅做检索**，不内置生成脚本（保持「纯规范、无脚本」定位）。

## Token 节省策略（Efficiency 效率）
- **先库后网**：用户已指定本地 / 知识库，或同一次会话已检索过同主题时，**优先复用已有结果**，仅联网补缺口，不重复全量联网。
- **压缩回传**：多路检索结果先归并为「标题 + 来源 + 适用性 + 一句话摘要」的紧凑条目，再进入正式整理；不在主对话展开网页原文。
- **按需读参考**：`references/` 仅在首次加载或用户切换场景时读取，不每次全量重读。
- **标准骨架锁版**：输出严格套用「标准输出格式」四模块，不随机增删章节、不堆砌链接。

## 冲突处理四步法
1. 明确列出冲突点。
2. 按可信度排序：官方教材及配套教师用书 > 省 / 市官方教研院 > 知名权威教育平台 > 普通教师博客。
3. 可信度层级可区分时，采信高层级来源，标注分歧及来源。
4. 可信度同级、无法判定时，**完整呈现各方观点与来源，并明确提示用户自行甄别、按需选用**——不强行统一。

## 标准输出格式（Effectiveness 有效）
- **检索摘要**：检索了什么（学科 / 学段 / 版本 / 主题 / 类型 / 场景 / 检索模式）及所用信源层级。
- **推荐资料列表**：按序排列，每条含 标题、来源（标注免费 / 付费 / 本地 / 知识库）、适用学段版本、质量评分（★）、核心内容摘要、可复用要点、**可直接引用的参考文献条（作者. 标题. 来源, 年份）**。
- **矛盾点提示**（存在冲突时）：分点列出各方观点 + 来源，并给建议或"请按需选用"提示。
- **补充说明**：版本 / 学段注意事项、"待核实"项、可替代检索建议。

## 硬性规则
- 禁止只给原始链接而无结构化、可复用内容。
- 禁止把未核实知识点当事实断言；必须标"待核实"。
- 付费 / 需登录资料须清晰标注，提供全文前确认。
- 仅检索与请求相关的资料，不发散到无关领域。
- 超出适用边界的请求须明确说明，不强行执行。
- 输出以"教师直接可用、课堂直接落地"为第一标准。

## 已知限制（Convention 规范）
- 依赖运行环境提供的检索能力，环境无联网且无本地 / 知识库指定时无法获取外部资料。
- LLM 可能幻觉，关键知识点、学段、版本需教师最终核验。
- 框架内时效表述（2022 版课标、"近3年"）需随官方更新手动同步。
- 付费 / 版权资源只定位不取全文。

## 可配置项
偏好的具体信源、输出篇幅、语言风格、是否附带"相似资料"推荐等可按用户习惯开关，不改动上述核心固定逻辑（详见 `references/preferences.md`）。
