# 智能出题组卷与题库整理工具（k12-paper-generator）

本工具为 K12（中小学）教培与自主学习场景提供题库的**整理**与**使用**两大能力：

- **整理**：解析题库 → 分门别类整理（题型/知识点/难度/来源文档四维"题库地图"）→ 相似题检测
- **使用**：按场景智能组卷（标准试卷）｜按学生学情挑题生成个性化整理册（学习材料）

## 能力边界

- 输入：zip 压缩包题库（内含 .txt / .md / .json / .docx 题目文件），或已解析的 bank.json
- 输出（整理）：题库地图（目录总览、题型分类目录、知识点分类目录、文档来源索引）、相似题检测报告、题型分类整理文档（年级·学科·知识点三级分类 + 难度层级标注）
- 输出（组卷）：结构化题库 bank.json、试卷（学生卷）、答案解析卷、组卷报告
- 输出（学情挑题）：个性化整理册（学生版 + 答案版 + 整理说明报告）
- 组卷场景：每日打卡练习、周测、月测、期中/期末模拟、专题训练
- 策略：按场景难度配比 + 知识点覆盖 + 薄弱点加权 + 去重 + 难度递进排序
- **题目溯源**：解析时自动提取题目来源（学校/试卷类型/年份/原卷题号，支持标签标注与文件名推断），组卷与挑题输出的**每道题前均标注来源**，答案卷/报告含来源列与来源覆盖统计

## 标准工作流程

### 流程 A：题库整理与按学情挑题（整理工作流）

适用场景：用户上传题库后想"整理归类题目"，或"按孩子情况挑选题目整理成学习材料"。

#### A1. 解析题库

用户上传 zip 题库后，运行解析脚本生成结构化题库与统计报告：

```bash
python3 scripts/parse_bank.py <题库.zip> [--out <输出目录>]
```

- 输出目录（默认为题库 zip 同目录）会生成 `bank.json`（结构化题目）与 `bank_stats.md`（题型/难度/知识点分布统计，含**题目来源覆盖统计**：按学校/试卷类型/年份统计、来源缺失题数）
- 解析规则详见 `references/bank-format-spec.md`（含来源标注规范：`【学校：X】【试卷类型：X】【年份：X】【题号：X】`，文件名如 `2024年川沙中学期中数学试卷.txt` 可自动推断）
- 解析完成后，**必须向用户展示题库统计摘要**（总题数、题型分布、知识点覆盖、难度分布、来源覆盖），并指出哪些题目缺少标签

#### A2. 分门别类整理题库（生成"题库地图"）

```bash
python3 scripts/organize_bank.py <bank.json 或 题库.zip> [--out <输出目录>]
  [--filter-type 选择题,填空题] [--filter-kp 知识点A] [--filter-diff 易,中,难] [--dedupe]
```

- 输出到 `<输出目录>/organized/`：**目录总览**、**题型分类目录**、**知识点分类目录**、**文档来源索引**；`--dedupe` 额外输出**相似题检测报告**
- 传 zip 会自动先调用 parse_bank.py 解析，无需手动两步
- 知识点分类目录是后续"按孩子情况挑题"的索引底稿；向用户展示时重点说明：题库覆盖哪些知识点、每个知识点题量与难度构成、哪些知识点薄弱题源充足/匮乏
- 用户想合并重复题时开启 `--dedupe`（题干归一化相似度 ≥88% 判定疑似重复）

#### A3. 确认学生画像

顾问式对话确认：年级与学科、**薄弱知识点**（必问，可从近期错题/考试成绩中提炼）、已掌握知识点（抽查巩固）、当前水平（近期分数或 基础/进阶/冲刺 判断）。

#### A4. 按学情挑题生成个性化整理册

```bash
python3 scripts/select_questions.py <bank.json> --weak "知识点1,知识点2"
  [--grade 八年级] [--subject 数学] [--student 小明]
  [--mastered "知识点3"] [--level 基础|进阶|冲刺] [--score 75]
  [--per-kp 5] [--exclude id1,id2] [--title 标题] [--out 输出目录]
```

- 输出三件套：`整理册_学生版.md`（按薄弱点分章节，组内 基础→中档→挑战 递进）、`整理册_答案版.md`（同结构含答案解析）、`整理报告.md`（学生画像、挑选逻辑、知识点覆盖、结构偏差、题库缺口、下次复用命令）
- `--score` 自动映射水平：<60 基础 / 60-79 进阶 / ≥80 冲刺；`--level` 显式指定优先
- 已掌握知识点（--mastered）各抽查 1 题保持手感，不做题海
- 完成一轮后向用户说明挑选逻辑与正确率记录方式，为下一轮动态调整做准备

#### A5. 动态迭代

- 正确率 <60% → 下次降一档难度（基础配比 5:3:2）；>80% → 升一档（冲刺 2:3:5）
- 连续多轮不重题：把上一轮 `整理报告.md` 中的 `--exclude` 列表传给下一轮
- 题库缺题（薄弱知识点无题可用）时如实告知缺口，建议补充题源；宁可少配题不硬凑

### 流程 B：智能组卷（组卷工作流）

适用场景：用户要的是标准试卷——每日打卡、周测/月测、期中期末模拟、专题训练。

#### B1. 确认组卷需求

根据对话场景确认组卷参数（信息不足时询问，齐全时可直接执行）：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 组卷类型 | daily（每日打卡）/ weekly（周测）/ monthly（月测）/ midterm（期中模拟）/ final（期末模拟）/ topic（专题训练） | 必填 |
| 学情数据 | 薄弱知识点列表（加权选题）、已掌握知识点（降低重复） | 可选 |
| 知识点范围 | 限定考查范围（专题训练必填） | 全部 |
| 题量 / 难度配比 | 各场景有默认结构，可覆盖 | 见策略文档 |
| 排除已做题目 | 传入已完成的题目 id 列表，实现"每日打卡不重题" | 可选 |

#### B2. 智能组卷

```bash
python3 scripts/compose_paper.py <bank.json> --type daily [--out <输出目录>] \
  [--weak "知识点1,知识点2"] [--mastered "知识点3"] [--kp "知识点A,知识点B"] \
  [--count N] [--ratio 4:1:1] [--exclude id1,id2] [--title 试卷标题] [--duration 30] [--subject 数学] [--grade 八年级]
```

- 输出三个文件：`paper_学生卷.md`、`paper_答案解析卷.md`、`paper_组卷报告.md`
- 各场景的默认结构、难度配比、学情调整规则详见 `references/paper-strategy.md`
- 组卷完成后，向用户展示试卷概要（题量、总分、时长、知识点覆盖、难度分布），并说明选题逻辑（例如"薄弱知识点'一元二次方程'占比 40%"）

#### B3. 动态调整与再组卷

用户对试卷不满意时支持快速调整后重跑 B2：

- 觉得难了 → 调低难度配比（如 `--ratio 6:3:1`）或减少中档题
- 想换题 → 传入 `--exclude` 排除当前试卷题目再组一份
- 打卡场景 → 把上一份试卷题目 id 加入 `--exclude`，实现"每天不重题"

### 流程 C：题型分类整理（题型分类整理工作流）

适用场景：用户上传题库后想"把题目按年级、学科、知识点分门别类整理成一份清晰的文档"，用于教学备课、知识点梳理或给学生发分类练习题单。

#### C1. 解析题库

与流程 A 相同，先运行 `parse_bank.py` 得到 bank.json（年级、学科由题库标签 `【年级：】【学科：】` 或文件名推断，如 `六年级数学_有理数.txt` → 六年级 / 数学；JSON 顶层 subject/grade 自动套用到该文件全部题目）。

#### C2. 三级分类整理

```bash
python3 scripts/classify_questions.py <bank.json 或 题库.zip> [--out <输出目录>]
  [--title 标题] [--filter-grade 六年级,八年级] [--filter-subject 数学] [--no-source]
```

- 输出单份 `题型分类整理.md`，结构为：**卷首说明 → 难度层级标注说明（星级图例）→ 分类目录（年级·学科·知识点三级，含每题型题数与难度构成）→ 分章节正文**
- 分类维度：**年级 → 学科 → 知识点（题型）**，例：`六年级 · 数学 → 有理数的加法题型`
- 每个题型分类内部**按难度从易到难（1→5）递增排列**；多知识点题目按**主知识点（第一个）**归类，原文完整保留不改动
- 每道题标注难度星级（★☆☆☆☆ 易 … ★★★★★ 难）；默认附 `📌 来源`（学校·年份·试卷类型·原卷题号），可用 `--no-source` 关闭
- 可用 `--filter-grade` / `--filter-subject` 限定范围（如只看某年级某学科）
- 向用户展示时说明：覆盖哪些年级学科、各知识点题型题量与难度梯度，便于教学取舍

## 学情驱动的出题策略（核心规则）

1. **薄弱点加权**：`--weak` 中的知识点选题权重 ×3，优先覆盖
2. **已掌握降权**：`--mastered` 中的知识点权重 ×0.5，避免重复无效刷题
3. **错题重练**：错题所在知识点建议在 3 天内的打卡卷中再次出现（由专家在对话中提醒用户加入 `--weak`）
4. **难度动态适配**：若学生近期正确率低，专家应主动建议下调难度配比；正确率高则上调中高档题比例
5. **递进排序**：试卷内题目按"基础 → 中档 → 综合"排列，打卡卷尤其如此，保护学生做题体验

## 输出规范

- 试卷必须包含：卷头（标题、年级学科、时长、总分）、大题分区（一、二、三…）、每题分值、页脚提示
- **每道题前必须标注题目来源**：`> 📌 来源：学校 · 年份年试卷类型 · 原卷第N题`；来源缺失的题目标注"来源：待补充（题库未标注）"
- 答案解析卷与试卷题号一一对应，含答案与解析（题库无解析时标注"解析待补充"），表格含**题目来源列**
- 组卷报告必须包含：选题清单表（含来源列）、难度分布表、知识点覆盖表、选题逻辑说明、**题目来源标注情况**（已标注/待补充题数与提示）
- 个性化整理册每道题前同样标注来源；答案版每题附"来源"行；整理报告含**来源标注情况**统计
- 试卷排版使用 `templates/paper-template.md`，报告使用 `templates/paper-report-template.md`
- 题库地图（organized/）：目录总览（总量/题型/难度/知识点/来源分布）、题型分类目录、知识点分类目录（含每知识点题量与难度构成）、文档来源索引
- 个性化整理册必须包含：卷头（标题、学生称呼、年级学科、整理日期）、本次整理说明（学生画像）、按薄弱知识点分章节（组内 基础→中档→挑战 递进、每章节标注难度构成）、已掌握知识点抽查区、尾注练习建议；答案版与章节一一对应含答案解析；整理报告含学生画像、挑选逻辑、知识点覆盖表、结构偏差、题库缺口、下次复用命令

## 注意事项

- 解析结果取决于题库标注质量：未标注题型/难度/知识点的题目只能按"未标注"处理，须提醒用户补充标签或允许专家基于题干人工判定后回写 bank.json
- 题目来源的优先级：题目标签（`【学校】`等）> 文件名推断 > 未标注；来源缺失不影响组卷，但报告中要如实提示缺失数，并建议用户在题库中逐步补全以便溯源
- 期中/期末模拟卷建议按上海本地考试结构组卷（如数学中考卷：选择/填空/解答的题量分值比例），具体参考策略文档
- 题库可能存在答案缺失，组卷报告须统计"无答案题目"数量并提醒
- 整理/挑题时某难度档题量不足会向相邻档"借题"，须在报告中如实说明结构偏差；薄弱知识点题库缺题时如实提示缺口，不硬凑
- 区分两种产出：整理工作流产出按知识点分组的**个性化学习材料**（巩固用），组卷工作流产出结构化**标准试卷**（检验用）；用户说"整理/归类/挑题/按孩子情况出练习"走流程 A，说"出卷/测试/模拟考"走流程 B
- 所有输出使用中文
