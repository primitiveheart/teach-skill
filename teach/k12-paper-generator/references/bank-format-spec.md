# 题库结构与解析规范

## 支持的输入格式

用户上传 **zip 压缩包**，内含以下格式的题目文件（可混合、可嵌套目录）：

| 格式 | 解析方式 |
|------|---------|
| `.json` | 结构化题库（推荐），直接按 schema 校验读取 |
| `.txt` / `.md` | 文本题库，按"题号分隔 + 标签行"启发式解析 |
| `.docx` | 提取正文文本后按文本题库规则解析 |
| 其他格式 | 跳过，并在统计报告中列出未识别文件 |

## 文本题库书写规范

每道题以**题号行**开头（`1.`、`1、`、`1）`、`【题1】`等），题干后可跟**标签行**与**答案行**：

```text
1. 已知关于x的方程 x² - 5x + k = 0 的一个根为 2，求 k 的值。
【题型：解答题】【知识点：一元二次方程】【难度：3】【分值：5】【学校：川沙中学】【试卷类型：期中】【年份：2024】【题号：18】
【答案】k = 6
【解析】将 x=2 代入方程得 4-10+k=0，解得 k=6。

2. 下列方程中是一元二次方程的是（　）
A. 2x+1=0　B. x²+3x=0　C. x/y=2　D. x³=1
【题型：选择题】【知识点：一元二次方程】【难度：1】【分值：4】
【答案】B
【解析】含一个未知数且最高次数为 2 的整式方程。
```

### 来源标注（题目溯源）

每道题可标注**来源信息**，组卷/挑题输出时会在每道题前自动附上来源，便于追溯出处：

| 标签 | 说明 | 示例 |
|------|------|------|
| 【学校：X】 | 题目出自哪所学校/机构 | 【学校：川沙中学】 |
| 【试卷类型：X】 | 期中 / 期末 / 模拟 / 升学 / 月考 / 单元测 / 其他 | 【试卷类型：期末】 |
| 【年份：X】 | 试卷年份，如 2024 / 2023-2024 | 【年份：2024】 |
| 【题号：X】 | 原卷中的题号（便于查证），可省略 | 【题号：18】 |

- 以上标签可写在题目行内、标签行或单独一行，支持别名：`【卷型】`→试卷类型、`【学年】`→年份、`【原题号】`/`【原卷题号】`→题号
- **文件名自动推断**：若题目文件命名规范（如 `2024年川沙中学初二数学期中试卷.txt`、`建平中学2023期末数学.docx`），解析器会自动从文件名提取学校、年份、试卷类型，无需逐题标注
- 优先级：**题目标签 > 文件名推断 > 未标注**（未标注来源的题目在组卷时标注"待补充"，报告中统计缺失数）
- 来源缺失不影响组卷，但会影响溯源，建议用户在题库中逐步补全

### 标签说明

| 标签 | 取值 | 缺省处理 |
|------|------|---------|
| 【题型：X】 | 选择题 / 填空题 / 解答题 / 判断题 / 计算题 / 证明题 / 应用题 / 作图题 / 实验题 / 阅读理解 / 写作 等 | `未标注` |
| 【知识点：X,Y】 | 逗号/顿号分隔多个 | `未标注` |
| 【难度：X】 | 1-5 整数（1 最易），也接受 易/较易/中/较难/难 | `未标注` |
| 【分值：X】 | 数字 | 按题型默认：选择/填空 4 分，解答 8 分 |
| 【答案：X】 | 自由文本 | `null`（报告中统计缺失数） |
| 【解析：X】 | 自由文本 | `null` |

- 标签行可拆成多行写，也可与题干同行
- 选择题选项行（A. B. C. D. 开头）自动并入题干
- 难度文字映射：易=1，较易=2，中=3，较难=4，难=5

## JSON 题库 Schema

```json
{
  "subject": "数学",
  "grade": "八年级",
  "questions": [
    {
      "id": "q001",
      "type": "选择题",
      "stem": "下列方程中是一元二次方程的是（　）\nA. 2x+1=0 ...",
      "difficulty": 1,
      "knowledge_points": ["一元二次方程"],
      "score": 4,
      "answer": "B",
      "explanation": "……",
      "source": "来源文件名",
      "school": "川沙中学",
      "exam_type": "期中",
      "year": "2024",
      "number": "18"
    }
  ]
}
```

- 顶层也接受题目数组 `[...]`
- 字段别名兼容：`question/body`→`stem`；`type/question_type`→`type`；`kp/tags/points`→`knowledge_points`；`difficulty/level`→`difficulty`；`score/points`→`score`；`school_name/school`→`school`；`paper_type/exam_type`→`exam_type`；`paper_year/year`→`year`；`number/original_no/qno`→`number`
- id 缺失时自动生成（`q` + 3 位序号）

## 解析输出

`bank.json`：

```json
{
  "subject": null,
  "grade": null,
  "questions": [ { ...规范化题目对象... } ]
}
```

规范化后字段：`id, type, stem, difficulty, knowledge_points, score, answer, explanation, source, school, exam_type, year, number, untagged`

- `untagged`：布尔，题型/难度/知识点任一缺失即为 true，组卷默认跳过
- `difficulty` 统一为 1-5 整数
- `school / exam_type / year / number`：题目来源信息（可为 null/空，不影响组卷）
- `source`：来源文件名（始终保留，用于回溯）

`bank_stats.md`：总题数、可组卷题数、题型分布表、难度分布表、知识点覆盖表（按出现次数降序）、**来源覆盖统计表**（按学校/试卷类型/年份统计题数、来源缺失题数）、无答案题目数、未识别文件列表。
