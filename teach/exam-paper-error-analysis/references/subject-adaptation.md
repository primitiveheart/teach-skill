# Subject Adaptation Guide

**MANDATORY - READ WHEN**: User specifies a vocational education subject (机电/数控、计算机、会计、护理、汽修、建筑、旅游、电商等)

## Basic Education Subjects

| Subject | Focus Areas | Typical Errors |
|---------|------------|----------------|
| **数学** | 概念理解、逻辑推理、计算过程、建模能力 | 概念不清、计算失误、方法选择错误 |
| **语文** | 阅读理解、表达逻辑、人物分析、写作结构 | 理解偏差、表达不完整、审题偏差 |
| **英语** | 语法结构、词汇运用、中式表达、语境理解 | 语法错误、中式英语、语境误判 |
| **物理** | 实验设计、变量控制、公式应用、物理模型 | 概念混淆、实验步骤错误、单位遗漏 |
| **化学** | 反应原理、方程式配平、实验现象、计算 | 方程式错误、实验现象描述不全 |
| **科学** | 变量控制、实验设计、数据解读、科学方法 | 变量混淆、结论缺乏证据 |

## Vocational Education Subjects

| Course Type | Focus Areas | Typical Errors |
|-------------|------------|----------------|
| **机电/数控类** | 图纸识读、加工工艺、设备操作规范、公差配合 | 工艺路线错误、参数选错、安全规程遗漏 |
| **计算机/信息技术类** | 代码逻辑、算法思维、调试能力、系统配置 | 逻辑分支遗漏、语法错误、调试方法不当 |
| **会计/财务类** | 准则应用、账务处理流程、税务计算、报表编制 | 科目用错、借贷方向颠倒、税率误用 |
| **护理/医学类** | 操作流程、用药安全、病例分析、无菌规范 | 操作顺序颠倒、剂量计算错误、无菌意识薄弱 |
| **汽修/汽车类** | 故障诊断逻辑、拆装规范、检测仪器使用 | 诊断思路跳跃、工具使用不当、安全防护遗漏 |
| **建筑/施工类** | 结构受力、施工工序、材料选用、安全规范 | 受力分析错误、工序颠倒、安全措施遗漏 |
| **旅游/服务类** | 服务流程、沟通技巧、应急处理、礼仪规范 | 流程缺失、话术不当、应急预案遗漏 |
| **电商/营销类** | 数据分析、营销策划、平台规则、客户沟通 | 数据解读错误、策略脱离实际、话术不专业 |

## Vocational Special Analysis Dimensions

When analyzing vocational education errors, ADD these dimensions:

1. **岗位能力映射**：这道错题反映了学生在哪个岗位核心能力上的不足？
2. **操作规范意识**：错误是否涉及安全规程、操作标准、行业规范的违反？
3. **真实情境迁移**：学生是否能在模拟实训中做对，但在真实工作情境中出错？
4. **工具/设备使用**：错误是否源于对专业工具、检测仪器、软件平台的不熟悉？
5. **职业素养表现**：错误是否反映出职业意识薄弱？（安全意识、质量意识、成本意识）

## Vocational Variant Question Design

- **基础巩固题**：重复核心操作步骤，强化规范意识
- **易错辨析题**：设置常见操作误区，训练判断能力
- **迁移应用题**：更换工作情境/设备型号/客户需求，检验方法迁移能力
