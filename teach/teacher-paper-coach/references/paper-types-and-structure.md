# 论文类型与结构模板

> 本文档是对《教师如何写论文——来自编辑的建议》（谢晓英，华东师范大学出版社，2023）第五、六章方法的独立归纳与改写，回答"按什么类型写"和"怎么组织"两个问题。建议结合原书阅读。

---

## 一、两大论文类型

依据写作切入角度不同，论文分为两类：

| 类型 | 核心定位 | 重点 | 适用素材 |
|------|---------|------|---------|
| **课例设计** | 阐释一节课的**设计思路与实施过程** | 教学设计 | 一节完整的、精心设计的课 |
| **课例分析** | 从**评课角度**分析一节课的某个方面 | 评课分析 | 一节课、片段教学、一次教研讨论 |

### 选题确定类型的判断方法

- 用户的素材是"我设计了一节 XX 课" → **课例设计**
- 用户的素材是"我听了/上了一节 XX 课，发现了 XX 问题" → **课例分析**
- 用户的素材是"我和学生/同行的对话，触发了 XX 思考" → **课例分析**或混合型

## 二、课例设计论文的结构模板

### 推荐结构（5 段式）

```
1. 教材分析 / 教学内容分析
2. 教学目标
3. 教学过程
   3.1 教学情境/任务设计
   3.2 关键环节 1
   3.3 关键环节 2
   3.4 总结与提升
4. 教学反思 / 设计意图说明
5. 参考文献
```

### 各部分写作要点

#### 1. 教材分析
- 内容在课程/教材中的地位
- 课标对应要求
- 教学重点与难点

#### 2. 教学目标
- 体现核心素养（按学科）
- 三维目标或素养目标
- 可观察、可评价

#### 3. 教学过程
- **教学情境**——为什么这样设计（呼应标题中的研究方法/视角）
- **任务/问题链**——学生的活动路径
- **关键环节**——重点突出 2-3 个亮点

#### 4. 教学反思
- 设计意图（呼应研究主题）
- 实施效果（数据/学生反馈）
- 改进方向

### 标题示例
- 《基于深度学习的初中信息科技项目化学习设计》
- 《"双减"背景下小学英语作业优化的实践探索》
- 《促进学生审辩式思维发展的学习活动设计——以"外卖之我见"为例》

## 三、课例分析论文的结构模板

### 推荐结构（4 段式）

```
1. 教学现象 / 案例描述
2. 教学问题分析
3. 改进策略与实施
4. 启示与建议
```

### 各部分写作要点

#### 1. 教学现象 / 案例描述
- 客观描述教学事件（不评价）
- 引用学生发言、课堂行为、作业样本等具体素材
- 篇幅约占全文 20-30%

#### 2. 教学问题分析
- 从课程标准、学科理论、教育学理论角度分析
- 指出问题背后的成因
- 篇幅约占全文 25-35%

#### 3. 改进策略与实施
- 给出具体、可操作的改进方案
- 配合教学片段说明
- 篇幅约占全文 25-35%

#### 4. 启示与建议
- 提炼出可迁移的经验
- 回应开头的现象/问题
- 篇幅约占全文 10-15%

### 标题示例
- 《统编教材下高中生法治意识培养的实施策略——以思政必修 3〈政治与法治〉为例》
- 《基于判例培养高中生法治意识的探究——以"从民法典看依法治国的全面推进"为例》

## 四、混合型论文结构

如果用户素材**既有设计也有分析**，建议采用"先设计 + 后反思"或"案例 + 反思"两种混合结构：

### 混合结构 1：设计 + 反思

```
1. 选题背景（问题驱动）
2. 教学设计
3. 实施过程
4. 教学反思（含数据分析）
5. 启示
```

### 混合结构 2：案例 + 评析

```
1. 案例呈现（多角度）
2. 案例分析（理论框架）
3. 改进策略
4. 总结与推广价值
```

### 适用场景
- 用户做了一节课并进行了反思
- 用户上了一节课后听了专家评课
- 用户有完整教学实录 + 后续修改版本

## 五、写作骨架生成器（脚本思路）

> 教练与用户对话时，可用以下流程为用户生成论文骨架：

### 输入
1. 用户选题
2. 用户素材类型（课例 / 教研 / 课题 / 调查数据）
3. 用户期望篇幅（2000 / 3000 / 5000 字）

### 输出（模板）
```
【标题】：（待用 writing-methods.md 六条原则打磨）
【摘要】：（待用 writing-methods.md 四要素结构生成）
【关键词】：（3-5 个，按 writing-methods.md 方法选取）
【引言】：（按 writing-methods.md 引言四类型选择）

【正文】
第一章：（基于上述结构模板）
第二章：
第三章：
（依选题调整）

【参考文献】：（5-15 篇，按 writing-methods.md 格式规范）
```

### 调用建议
用户说"我想写一篇 XX 论文"时，先问清楚三件事：
1. 你手头的主要素材是什么？（一节课/一次教研/一份数据/一个课题）
2. 你想突出什么？（设计亮点 / 问题分析 / 改进策略）
3. 目标字数和刊物级别？（决定深度）

然后按上述模板给骨架，再引导用户填空。

## 六、常见结构问题与编辑说

### 问题 1：结构散乱，各部分比例失调

- 案例描述 1000 字，改进策略 200 字——本末倒置
- 解决：严格按"案例 20-30% + 分析 25-35% + 策略 25-35% + 启示 10-15%"配比

### 问题 2：教学过程写成"教学实录"

- 把整节课每分钟发生什么全写下来——这不是论文，是课堂实录
- 解决：只写**关键环节**，其他概括；用"在 XX 环节，教师……学生……"的简写

### 问题 3：分析部分空泛

- 只说"这个案例体现了 XX 理念"——没有具体分析
- 解决：用**课标依据 + 理论依据 + 数据/学生反馈**三层支撑

### 问题 4：结论无新意

- "通过本课教学，学生掌握了 XX 知识"——这是教学目标，不是研究结论
- 解决：结论要回答"研究发现了什么"，比如"实验表明，XX 方法比传统方法在 XX 维度上提升 X%"或"案例分析提示，XX 教学设计应满足 XX 条件"

## 七、文献综述与研究方法（简明提示）

> **编辑说**：教师论文（特别是评职称或冲高级）必须有"研究方法"段，哪怕只有一两句。

### 适合中小学教师的研究方法

| 方法 | 适用场景 | 写法提示 |
|------|---------|---------|
| **案例研究法** | 单节课、单个学生案例 | "本文以 XX 课为例，采用案例研究法……" |
| **行动研究法** | 教师改进自身实践 | "本文采用行动研究法，经过 XX 轮实践……" |
| **问卷调查法** | 有学生/教师数据 | "本文对 XX 学生发放问卷 XX 份，回收 XX 份……" |
| **访谈法** | 深度了解学生/教师 | "本文对 XX 名学生进行半结构化访谈……" |
| **文本分析法** | 分析教材/作业/课堂实录 | "本文对 XX 篇教学设计进行文本分析……" |

### 选题与方法的匹配

- 课例设计类 → 多用"案例研究法"
- 课例分析类 → 多用"案例研究法 + 文本分析法"
- 课题转化类 → 多用"行动研究法 / 实验研究法"
- 调查报告类 → 多用"问卷调查法 + 访谈法"
