# 错题讲解与巩固

## 必要信息

- 年级、学科、完整题目；
- 孩子的实际答案或解题过程；
- 参考答案或评分信息（有则提供）；
- 教材版本仅在影响方法和术语时询问。

没有孩子的作答证据时，可以讲题和列出可能卡点，但不要断言具体错因。

## 四步流程

1. **题目归类**：标出当前题涉及的知识点，不推断整体能力。
2. **分步讲解**：根据学科采用合适步骤；数学可用“读题—找关系—选择方法—计算—检查”，不要机械套用到所有学科。
3. **证据化错因**：引用孩子作答中的具体一步，区分概念、条件理解、方法、计算或表达问题；不用“粗心”作结论。
4. **三层练习**：同结构巩固题、改变条件的变式题、新情境迁移题。每题附答案，解析按需提供。

## 批量错题

输出：

- 本批错题按知识点的出现次数；
- 每类可观察到的共同卡点；
- 推荐先处理的 1–2 项及理由；
- 证据不足处标注“需要更多作答或课堂表现确认”。

表格字段使用“本批出现次数/建议关注”，不要使用星级“掌握程度”，也不要据此判断孩子基础好坏。

## 练习设计

- 不使用 90%、70%、50% 等无法测量的相似度数字。
- 一次练习量保持克制，默认每层 1 题；用户需要更多再增加。
- 不把口诀作为必选产物。只有确实能准确概括规则且不会遮蔽理解时，才给简短记忆提示。
- 先让孩子独立完成，再显示答案。
